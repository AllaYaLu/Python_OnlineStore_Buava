# Buava Store — Интернет-магазин и сервис аренды настольных игр

Полнофункциональный веб-сервис для покупки и посуточной аренды настольных игр и аксессуаров, разработанный на **Django 6.1** с использованием **PostgreSQL** и контейнеризации **Docker**.

## Основные возможности

### Для покупателей
* **Два формата витрины:**
  * **Главная страница (`/`):** компактные карточки новинок и популярных игр с приоритетной сортировкой товаров в наличии.
  * **Каталог (`/catalog/`):** полный список игр с описаниями, поиском по названию/описанию, фильтрацией по категориям и формату сделки (покупка или аренда), а также сортировкой по цене.
* **Гибкая модель сделок:** поддержка товаров «Только продажа», «Только аренда» и «Продажа и аренда» с раздельным расчетом стоимости в корзине.
* **Избранное и Сравнение игр:** сохранение понравившихся игр в избранное (для авторизованных пользователей) и таблица сравнения до 4 игр (работает на сессиях даже для неавторизованных гостей).
* **Корзина и Заказы:** изменение количества (`+` / `−`), удаление позиций, живые счетчики в шапке (`context_processors`), всплывающие уведомления при добавлении в корзину, автоматическое списание остатков со склада при оформлении заказа.
* **Личный кабинет (`/users/profile/`):** регистрация, авторизация, редактирование контактных данных и адреса доставки, просмотр истории заказов и их статусов.

### Для администраторов
* **Кастомизированная админ-панель (`django-admin-interface`):** управление категориями, товарами, остатками на складе (`StockInline`) и заказами.
* **Динамические бейджи (`django-colorfield`):** создание произвольных бейджей («Хит», «Новинка», «Выбор пользователей» и др.) с выбором цвета фона и текста через палитру с предпросмотром.
* **Автоматическая оптимизация изображений:** конвертация загружаемых `.jfif` файлов в `.jpg` на уровне модели `Product`.

## Технологический стек
* **Backend:** Python 3.12, Django 6.1, Gunicorn
* **База данных:** PostgreSQL 16
* **Frontend:** HTML5 (шаблонизатор Django), CSS3 (адаптивная сетка, БЭМ)
* **Инфраструктура и качество кода:** Docker, Docker Compose, WhiteNoise, Ruff (PEP 8), Django TestCase

## Запуск проекта через Docker

1. **Клонируйте репозиторий и перейдите в директорию проекта:**
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd online_store
   ```

2. **Создайте файл `.env` на основе `.env.example`:**
   ```env
   SECRET_KEY=your-secret-key
   DEBUG=True
   ALLOWED_HOSTS=localhost,127.0.0.1
   DB_NAME=online_store
   DB_USER=user
   DB_PASSWORD=your_password
   DB_HOST=db
   DB_PORT=5432
   ```

3. **Соберите и запустите контейнеры в фоновом режиме:**
   ```bash
   docker compose up -d --build
   ```

4. **Примените миграции и создайте суперпользователя:**
   ```bash
   docker compose exec web python manage.py migrate
   docker compose exec web python manage.py createsuperuser
   ```

После запуска сайт будет доступен по адресу: `http://127.0.0`, админ-панель — `http://127.0.0admin/`.

## Запуск автотестов

В проекте реализованы модульные и интеграционные тесты моделей и представлений (`store/tests/`):
```bash
docker compose exec web python manage.py test store
```
