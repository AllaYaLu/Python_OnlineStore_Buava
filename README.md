# 🛒 Учебный проект: Интернет-магазин на Django & PostgreSQL

Полнофункциональное веб-приложение интернет-магазина, разработанное в рамках учебного курса. Проект включает в себя управление каталогом товаров, складскими остатками, корзиной покупателя, оформлением заказов, а также кастомную систему регистрации пользователей и кастомные команды управления.

## 🛠 Стек технологий
* **Backend:** Python 3.12+ / Django 5.x / 6.x
* **Database:** PostgreSQL (основная) / SQLite (локальный кэш)
* **Environment Management:** django-environ (`.env`)
* **Interface:** django-admin-interface

---

## 🚀 Инструкция по локальному запуску проекта

### 1. Подготовка окружения и установка зависимостей
Склонируйте проект (или распакуйте архив), откройте терминал в папке проекта и активируйте виртуальное окружение:
```bash
# Для Windows:
.venv\Scripts\activate

# Для macOS / Linux:
source .venv/bin/activate
```

Установите все необходимые библиотеки из файла зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (`.env`)
В корне проекта (рядом с `manage.py`) необходимо создать файл `.env` для безопасного хранения конфиденциальных данных и подключения к PostgreSQL. 

**Пример содержимого файла `.env`:**
```ini
SECRET_KEY=django-insecure-(q^kc=#gszdu)0l#@rni=m1sgevuu2z$r*-8u2515_1w6o5#!*
DEBUG=True
DATABASE_URL=postgres://postgres:ВАШ_ПАРОЛЬ@localhost:5432/имя_вашей_базы
```
*Убедитесь, что указанная база данных предварительно создана в вашей СУБД (PostgreSQL).*

### 3. Применение миграций и сбор статики
Создайте структуру таблиц в базе данных и соберите статические файлы для кастомизированной админки:
```bash
python manage.py migrate
python manage.py collectstatic --clear
```
*На запрос терминала о сборе статики введите `yes`.*

### 4. Создание суперпользователя (Администратора)
Для доступа в административную панель создайте аккаунт главного администратора:
```bash
python manage.py createsuperuser
```

### 5. Запуск сервера разработки
Запустите локальный веб-сервер:
```bash
python manage.py runserver
```
После запуска проект будет доступен по следующим адресам:
* **Каталог товаров (Витрина):** `http://127.0.0`
* **Просмотр корзины:** `http://127.0.0`
* **Регистрация аккаунта:** `http://127.0.0`
* **Административная панель:** `http://127.0.0`

## ⚙️ Кастомные команды управления (Management Commands)

В рамках Задания №8 были реализованы две консольные команды для автоматизации работы со складскими запасами:

1. **Выгрузка (экспорт) остатков товаров со склада в JSON-файл:**
   ```bash
   python manage.py unload_product_residue
   ```
   *Команда формирует файл `residue.json` в корне проекта на основе модели Stock.*

2. **Загрузка (импорт) товаров и остатков из JSON-файла:**
   ```bash
   python manage.py load_goods
   ```
   *Команда автоматически импортирует данные в базу из файла `data.json`. Перед запуском переименуйте сгенерированный файл `residue.json` в `data.json` или подготовьте свой фикстура-файл.*
